# Security policy

## Supported versions

Only the latest release of `@limetech/n8n-nodes-lime-crm` gets security fixes.

## Reporting a vulnerability

Please don't report security problems in public issues.

Report them privately through GitHub instead, using the
[vulnerability report form](https://github.com/Lundalogik/lime-n8n-nodes-crm/security/advisories/new).
Only the maintainers can see the report.

Include what you found, how to reproduce it, and which version you used. We
will reply in the advisory.
